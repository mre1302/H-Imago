Política de firma de código

Los instaladores de Windows de H-IMAGO se firman con SignPath.io y el certificado de SignPath Foundation a partir de la versión 0.0.29.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Qué se firma

  • H-IMAGO.exe: el ejecutable de la aplicación que va dentro del instalador y del ZIP portable.
  • H-IMAGO-<versión>-Setup.exe: el instalador NSIS para Windows de 64 bits.
  • H-IMAGO-<versión>-win-x64-portable.zip: la versión portable. Contiene el H-IMAGO.exe firmado; el ZIP en sí no lleva firma Authenticode.

Primero se firma el ejecutable de la aplicación. Después se construye el instalador alrededor de ese ejecutable y se firma el instalador en una segunda solicitud.

Cómo se construye y se firma

  • El código es público en GitHub.
  • Las builds se generan en runners windows-latest de GitHub Actions con el workflow windows-release.yml.
  • Antes de empaquetar se comprueba que el ejecutable declara el nombre H-IMAGO y la versión de package.json.
  • El ejecutable sin firmar se envía a SignPath.io. Tras la aprobación se descarga, se verifica su firma y sustituye al ejecutable sin firmar antes de crear el instalador.
  • El instalador se envía a SignPath.io en una segunda solicitud, se aprueba, se verifica y se publica.
  • La clave privada está en un HSM de SignPath.io. El proyecto no la almacena ni tiene acceso a ella.
  • Cada solicitud de firma requiere la aprobación manual del aprobador del proyecto.
  • SignPath verifica que los artefactos firmados proceden de este repositorio y de la build registrada en GitHub Actions.

Roles

  • Autor: @mre1302
  • Revisor: @mre1302
  • Aprobador: @mre1302

El proyecto tiene un solo mantenedor, por lo que la misma persona ejerce los tres roles. Las contribuciones de otras personas se revisan antes de integrarse. Todos los mantenedores usan autenticación multifactor en GitHub y en SignPath.

Privacidad

La aplicación guarda los datos en local con SQLite por defecto. Solo se conecta a un servidor MySQL externo si el usuario lo configura, y solo solicita teselas de mapa cuando abre el georreferenciador. La aplicación de escritorio no incluye telemetría. El aviso de privacidad del sitio está en Contenido y derechos.

Verificar una descarga

A partir de la versión 0.0.29, cada release publica sumas SHA-256 y una atestación de procedencia de GitHub Actions. Windows añade además la firma Authenticode de SignPath Foundation.

Windows

Get-AuthenticodeSignature .\H-IMAGO-0.0.29-Setup.exe
Get-FileHash .\H-IMAGO-0.0.29-Setup.exe -Algorithm SHA256

También puedes ver la firma en las propiedades del archivo, pestaña Firmas digitales.

Linux

sha256sum -c SHA256SUMS-linux.txt
gh attestation verify H-IMAGO-0.0.29.AppImage --repo mre1302/H-Imago

Los artefactos de Linux no llevan firma Authenticode. Su integridad se comprueba con la suma SHA-256 y con la atestación de procedencia. Más información en la documentación de GitHub.

Estado

La solicitud de alta en SignPath Foundation está en preparación. La firma se activará en la versión 0.0.29; hasta su aprobación, las builds se publican sin firmar. La versión 0.0.28 y anteriores no están firmadas.
